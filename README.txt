# Raudra & Sanchi — Wedding Invitation Website

A responsive, single-page wedding invitation website built with plain HTML, CSS and JavaScript.

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in a browser.

## Publish it so you can share a public link
**Netlify (easy option):**
1. Go to https://app.netlify.com/drop
2. Sign in or create a free account.
3. Drag the extracted `raudra-sanchi-wedding-website` folder onto the page.
4. Netlify will publish it and provide a public URL you can share on WhatsApp.

You can also upload the folder to GitHub and deploy it with GitHub Pages.

## Included
- Mobile-friendly design
- All three event details and venue directions
- Countdown to the first event
- Original invitation-card gallery with enlarged preview
- Share/copy invitation link
- Add-to-calendar downloads for each event

## Important details to verify before publishing
The wedding invitation image lists the wedding venue as “Chembur, Mumbai – 74”. The site preserves that wording. Please confirm the preferred postal PIN/address format.
Calendar event end times are approximate placeholders because the invitation cards do not specify end times. Edit `script.js` if you want to change them.
